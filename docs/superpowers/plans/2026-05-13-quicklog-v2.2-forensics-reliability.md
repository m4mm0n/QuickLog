# QuickLog v2.2 Forensics Reliability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the v2.2 forensics and reliability upgrade for QuickLog while preserving zero external runtime dependencies.

**Architecture:** Extend the existing async pipeline and sink model rather than adding a new logging abstraction. Public configuration stays centered on `LoggerOptions` and `QuickLogger`; new capability classes are small, explicit, and dependency-free.

**Tech Stack:** C#/.NET 10 source, xUnit tests, BCL-only runtime APIs (`System.IO`, `System.Diagnostics`, `System.Text.Json`, `System.Threading`).

---

## Guardrails

- No GitHub push, no PR, and no remote write until the user explicitly asks.
- Use TDD for production behavior changes: write a failing test, verify it fails, implement, verify it passes.
- Keep features opt-in unless preserving existing behavior requires a default.
- Keep runtime dependencies at zero external packages.
- Preserve existing public APIs unless a change is additive.
- Run `dotnet test QuickLog.sln` at the end of every phase.

```csharp
using System.Diagnostics;
using System.Threading;

namespace QuickLog;

public static class LogContext
{
    private sealed class Frame
    {
        public Frame? Parent { get; init; }
        public string? Scope { get; init; }
        public string? CorrelationId { get; init; }
    }

    private sealed class PopHandle(Frame? previous) : IDisposable
    {
        public void Dispose() => _current.Value = previous;
    }

    private static readonly AsyncLocal<Frame?> _current = new();

    public static string? CurrentScope => _current.Value?.Scope;
    public static string? CurrentCorrelationId => _current.Value?.CorrelationId;
    public static string? CurrentTraceId => Activity.Current?.TraceId.ToString();
    public static string? CurrentSpanId => Activity.Current?.SpanId.ToString();

    public static IDisposable BeginScope(string name, object? value = null)
    {
        var previous = _current.Value;
        _current.Value = new Frame
        {
            Parent = previous,
            Scope = value is null ? name : $"{name}:{value}",
            CorrelationId = previous?.CorrelationId
        };
        return new PopHandle(previous);
    }

    public static IDisposable BeginCorrelation(string correlationId)
    {
        var previous = _current.Value;
        _current.Value = new Frame
        {
            Parent = previous,
            Scope = previous?.Scope,
            CorrelationId = correlationId
        };
        return new PopHandle(previous);
    }
}
```
